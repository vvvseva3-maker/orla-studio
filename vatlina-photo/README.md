# Vatlina Photo — сайт-портфолио

Одностраничный сайт на чистом HTML, CSS и JavaScript: без сборки, фреймворков и `npm install`. Можно открыть `index.html` двойным кликом или залить папку на любой хостинг.

## Что внутри

| Раздел | Что делает |
|---|---|
| Шапка и первый экран | Имя, слоган, меню, кнопка «Записаться на съёмку». На телефоне меню открывается на весь экран. Внизу первого экрана — подсказка с сегодняшним золотым часом. |
| Портфолио | Сетка-«кирпичики» с фильтрами (Портреты, Репортаж, Пейзаж, Love Story). По клику фото открывается на весь экран: стрелки, клавиши ← →, свайп, Esc. |
| Свет и погода | Рассвет, закат, утренний и вечерний золотой и синий час, шкала дня с отметкой «сейчас» и обратным отсчётом. Погода сейчас или к золотому часу выбранного дня, совет фотографа. Можно выбрать город из списка, найти любой другой или определить своё местоположение; дату — на год вперёд. |
| Когда лучше сниматься | Карточки про золотой и синий час, пасмурный день и полдень. Советы, что надеть: карточка под текущий прогноз подсвечивается. |
| Запись и контакты | Форма: имя, телефон или Telegram, дата (с подсказкой золотого часа на этот день), тип съёмки, комментарий. Кнопки Telegram, WhatsApp, Instagram, телефон, почта. |

## Файлы

```
index.html        разметка всех разделов
css/styles.css    стили; цвета и шрифты — в переменных в начале файла
js/config.js      ВСЕ НАСТРОЙКИ: имя, контакты, города, фото, отправка формы
js/sun.js         расчёт солнца (работает без интернета)
js/weather.js     погода Open-Meteo и логика советов
js/main.js        интерфейс: меню, галерея, просмотр фото, виджет, форма
```

## Как настроить

Всё основное — в `js/config.js`, там же комментарии к каждому полю.

1. **Название и город.** `name` (Vatlina Photo), `logoMain` и `logoSub` (логотип), `role`, `baseCity`. Заголовок страницы и описание для Google поменяйте в начале `index.html` (`<title>` и `<meta name="description">`).
2. **Контакты.** В `contacts` впишите свои Telegram, Instagram (без @), WhatsApp (цифрами с кодом страны), телефон и почту. Пока поля пустые, блок контактов не показывается.
3. **Фото.** В `photos` сейчас примеры с Unsplash. Свои фото положите в папку `images/` и укажите так:
   ```js
   { src: 'images/portrait-1.jpg', full: 'images/portrait-1-big.jpg', category: 'portrait', ratio: 4 / 5, title: 'Анна', place: 'Синтра' }
   ```
   `src` — превью около 900 px по ширине (WebP или JPG до 200 КБ), `full` — большая версия около 2000 px. `ratio` — пропорции превью: `4 / 5` вертикальное, `3 / 2` горизонтальное. Фото первого экрана — в `heroPhoto` (`{ src: 'images/hero.jpg' }`).
4. **Категории.** Список `categories` задаёт кнопки фильтра и типы съёмки в форме. `key` у категории должен совпадать с `category` у фото.
5. **Города для виджета.** `locations`: название, координаты и часовой пояс. Первый город — по умолчанию.
6. **Цвета и шрифты.** Переменные в начале `css/styles.css`: `--gold` — акцент, `--paper` — светлый фон, `--night` — тёмные разделы.

## Как получать заявки

Без настройки форма не отправляет данные никуда. После нажатия кнопки посетитель видит готовый текст заявки и кнопки «Скопировать», Telegram, WhatsApp и почта.

Чтобы заявки приходили на почту автоматически:

1. Зарегистрируйтесь на [formspree.io](https://formspree.io) (есть бесплатный тариф) и создайте форму.
2. Скопируйте адрес вида `https://formspree.io/f/abcdwxyz`.
3. Вставьте его в `formEndpoint` в `js/config.js`.

Подойдёт и любой другой сервис или свой сервер, который принимает JSON методом POST.

## Погода: важно про лицензию

Погода и поиск городов берутся из [Open-Meteo](https://open-meteo.com). Ключ не нужен, но **бесплатный доступ разрешён только для некоммерческих сайтов** (до 10 000 запросов в день, нужна ссылка на источник — она уже есть на сайте). Для сайта, через который вы продаёте съёмки, по правилам Open-Meteo нужен платный план: купите его и вставьте ключ в `weatherApiKey` — сайт сам переключится на коммерческий адрес API. Сверьте адреса с документацией Open-Meteo после покупки.

Рассвет, закат и золотой час от погоды не зависят: они считаются в браузере и работают даже без интернета. Точность — около минуты, этого хватает для планирования съёмки.

Кнопка «Моё местоположение» работает только на сайте с `https://` (на любом нормальном хостинге это так), браузер спросит разрешение.

## Как выложить в интернет

- **Netlify Drop**: зайдите на [app.netlify.com/drop](https://app.netlify.com/drop) и перетащите папку сайта. Через минуту будет ссылка, потом можно подключить свой домен.
- **GitHub Pages**: загрузите файлы в репозиторий → Settings → Pages → Branch `main` → Save.
- **Любой хостинг**: загрузите все файлы как есть в корень сайта.

## Проверено

- Ширина 1440 и 390 px, без горизонтальной прокрутки; меню, фильтры, просмотр фото (стрелки, клавиатура), смена города и даты, форма.
- Время солнца сверено с астрономической библиотекой `astral` для Лиссабона, Порту, Москвы и Сиднея: расхождение 1–2 минуты.
- Учитывается настройка «уменьшить движение»: анимации отключаются.
