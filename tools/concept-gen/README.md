# Генератор быстрых прототипов

Один YAML на заведение в `sites/` → `python3 gen.py [slug]` → `concepts/<slug>/index.html`.

- `template.html` — общая страница (PT/EN, живой статус «открыто/закрыто» по Лиссабону, часы, меню, форма → сообщение в директ Instagram, плашка «Conceito», noindex).
- `motifs.py` — иллюстрации для первого экрана (круассан, гриль, бокалы, цветы, азулежу и т. д.), цвета берутся из палитры сайта.
- `preview.py` — скриншоты 1440 и 390 с локальными шрифтами (`@fontsource`), проверка горизонтальной прокрутки и формы, `--og` делает `og.jpg` для превью ссылки.

В YAML: `look` (шрифты, палитра, вариант первого экрана `split` / `type` / `poster`, меню `cards` / `list` / `carta`, мотив), `hours`, `form` (`order` / `table` / `bouquet` / `enquiry`), `items`, `facts`, тексты `t.pt` / `t.en`. Факты, цены и часы — только из источников.
